# Novel Writer

This skill helps you write the actual content of your novel, chapter by chapter.

## Usage

Invoke this skill when you have a chapter outline and are ready to write.

## Process

1. **Ask for Chapter Outline**:
   - Ask for the specific chapter outline to write.

2. **Generate Content**:
   - Use the following prompt template to write the chapter.

### Prompt Template

```
【任务】根据章节大纲创作正文，正文字数5500字以上（底线：单章≥5500字，两章合计≥12000字）

【选定选题】
步骤1选择的书名和简介{1-选题.txt}
【书籍设定】
步骤2生成的{2-核心设定.txt}

【章节大纲】
{粘贴步骤5的该章大纲}

【核心要求】（必须严格遵守）
1. **上下文衔接**：
   - 上一章结尾：{粘贴上一章最后一段}
   - 本章开篇需自然承接

2. **网文格式**：
   - 多用短句、短段落（一段≤3行）
   - 适合手机竖屏滑动阅读
   - 避免大段环境描写/心理活动

3. **风格调性**：
   - {搞笑风：多用梗/吐槽/反差}
   - {热血风：短句+动词+情绪渲染}
   - {甜宠风：细节+互动+心跳感}
   - 参考上一章的语言风格保持一致

4. **字数控制**：
   - 5500字以上（底线：单章≥5500字，两章合计≥12000字）
   - 不足则补充细节扩写，超出6500字以上则删减废话

5. **剧情截断**【重要】：
   - 严格按照大纲写到"结尾钩子"处立刻停下
   - 不要提前写下一章内容
   - 不要写总结性结尾（如"他决定……"然后结束）
   - 钩子要卡在：
     - 系统提示一半
     - 门被推开但没说是谁
     - 关键话说一半被打断
     - 危险临近但没发生

【对话要求】
- 人物说话要符合身份（配角有口癖/主角有性格）
- 避免"说教式"长篇大论
- 对话停顿用省略号（"轮换..."），不用破折号

【爽点检查】
- 本章是否有至少1个小高潮？
- 主角是否展现了能力/智商/魅力？
- 读者看完会不会想点下一章？

【写作铁律速查】（违反即不合格）
- 禁用：「不是X是Y」一切变体、「没有X只有Y」铺垫、数字递增式描写、废话式对答（"用了。有用。"）、精灵图鉴式对白（对话不列数据报告）
- 标点：疑问反问必用？、全篇禁止句号到底、破折号一章最多一个、对话停顿用省略号
- 分段：一段≤5句、一个信息单元；关键动作/发现/骂人话独句成段；适合手机竖屏（一段≤3行）
- 废话：白描到位即停不加解释、不自明感官追加解释句（"空的""马蹄踏的"）；独词成段感官标签（。X的。）删除；已设设定不通过角色对话提醒读者
- 衔接：章首不重复上章结尾、相邻段落有逻辑关联、闪回须有触发点、结尾必留钩子且不用总结性判断收尾
- 叙事：形容词前置不碎词（"很轻地擦过"非"擦过，很轻"）、暖在冷前、自我审判用问句收
- 用词：高频意象词单章内不重复（同一意象词≤2次）；游戏术语不泄漏（"刷新点"→"活动范围"，"BOSS"→"那东西"）
- 世界观：术语西幻底色（炼金釜/药剂不写丹炉/丹药）、物品逻辑自洽、精灵进化是生物性非渡劫飞升
- 修改：写完跑自检脚本（check.sh/check.py）并人工复核，见下方第 4 步；三遍全过→衔接→读感→字数（最后一环），字数不达标回滚扩写

【输出格式】
先输出第x章 章节标题
然后是正文内容
```

3. **Output**:
   - Save the content to a file named `8-正文-第X章.txt`.

4. **写完自查（脚本+人工，全部通过才能提交）**：
   - 跑自检脚本（`check.sh` / `check.py`）：自动扫描破折号、问号缺失、禁用句式（不是X是Y/没有X只有Y/数字递增）、句末碎词、独词感官、副词、超5句段落、高频意象、字数——逐项看输出，有违规当场修；
   - 再按上文【写作铁律速查】人工复核脚本漏掉的项：「不是X是Y」反向变体、废话式对答、章首重复、游戏术语泄漏、精灵图鉴式对白、废话总结句、高频词（同一意象词单章≤2次）、世界观术语（炼金釜/药剂不写丹炉/丹药、物品逻辑自洽）、逻辑一致性（人物能力/持有物/时间线/精灵状态/剧情事实是否前后矛盾）、修改处专项复查（修改过的段落单独查废话/逻辑错误/新增破折号）；
   - 字数不达标回滚扩写，扩写完从头再查。
